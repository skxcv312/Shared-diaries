### 1. 회원 (User)

#### 회원가입

- 이메일과 비밀번호를 입력하여 가입
- 비밀번호는 암호화하여 저장
- 이메일 중복 여부를 체크

#### 로그인

- 이메일과 비밀번호를 입력하여 인증
- JWT AccessToken과 RefreshToken 발급

#### AccessToken 재발급

- RefreshToken을 사용하여 AccessToken 재발급
- RefreshToken 만료 시 재로그인 필요

#### 로그아웃

- 서버 저장소에 존재하는 RefreshToken 삭제 (선택적)

#### 회원 정보 조회

- 자신의 프로필 정보를 조회 (이메일, 가입일자 등)

---

### 2. 일기 (Diary)

#### 일기 작성

- 제목과 내용을 입력하여 일기 작성
- 공개 여부를 설정 (공개 / 비공개)

#### 일기 수정

- 본인이 작성한 일기만 수정 가능

#### 일기 삭제

- 본인이 작성한 일기만 삭제 가능

#### 일기 조회

- 본인이 작성한 모든 일기 리스트 조회
- 단일 일기 상세 조회

#### 공개 일기 조회

- 다른 사용자가 공개한 일기 리스트 조회
- 단일 공개 일기 상세 조회

---

### 3. 일기 공유 (공개 기능)

#### 공개/비공개 전환

- 작성한 일기의 공개 설정을 수정 가능

#### 공개 일기 리스트

- 전체 공개된 일기 리스트 조회 (페이징 처리)

#### 공개 일기 검색

- 제목 또는 내용 기반 검색 가능

---

### 4. 기타

#### 에러 응답 통일

- 에러코드와 에러메시지 형식을 통일하여 API 응답

#### 페이징 처리

- 공개 일기 리스트와 개인 일기 리스트 조회 시 페이징 적용

#### API 인증

- 모든 민감 요청은 AccessToken이 필요
- AccessToken 만료 시 RefreshToken으로 갱신 가능

#### 보안

- 비밀번호는 해시하여 안전하게 저장
- RefreshToken은 안전하게 관리 (서버 저장 또는 쿠키 등 고려)

#### 테스트 코드

- 모든 비즈니스 로직에 대해 테스트 코드 작성
